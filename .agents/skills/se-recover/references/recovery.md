# Recovery reference

Containment first: freeze the affected scope, preserve evidence, and identify recorded source-to-run-to-artifact relationships. A graph of receipts identifies possible exposure; it does not prove model reliance.

Restoration must use a reviewed baseline and preserve later revocation events. Do not overwrite live state with an old snapshot, resume a contaminated conversation, or declare an external effect undone without checking the external system. Effects with missing status are `uncertain` and require investigation or human handling.
