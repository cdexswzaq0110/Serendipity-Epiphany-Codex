# Conditional smell baseline

Use these as prompts, not automatic violations: Mysterious Name, Duplicated Code, Feature Envy, Data Clumps, Primitive Obsession, Repeated Switches, Shotgun Surgery, Divergent Change, Speculative Generality, Message Chains, Middle Man, Refused Bequest, Silent Swallow, Phantom Config, and Test That Cannot Fail.

Explicit repository rules override this baseline. Tool-enforced formatting or lint findings are not architectural smells. Report a possible smell with evidence and impact rather than declaring a violation from the name alone.
