# Design deliverable template

1. Requirements: functional/non-functional, assumptions, out-of-scope.
2. Estimates and first bottleneck.
3. Entities, data, invariants, and state.
4. API contract and checklist.
5. Architecture and numbered flows.
6. Deep dives with rejected alternatives and verification.
7. Data layer and consistency choices.
8. Resilience and observability.
9. Trade-offs and risks.
10. Remaining limits and open decisions.

Attach evidence to factual claims and identify assumptions. Never include secrets or pretend an unverified capacity number is measured.
